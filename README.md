## 安装

1. **解压** zip 到你想放的位置（路径里可以有中文和空格）。
2. **双击 `安装.cmd`**。它会依次做四件事：装发布依赖 → 环境自检 → 设开机自启 → 启动并打开首页。
3. 看到「装好了」即可。浏览器会自动打开 `http://127.0.0.1:8810/`，第一次进入让你设一个**访问口令** —— 那是你自己空间的钥匙。

装好之后开机自动启动，不用再双击任何文件。想手动起一次就双击 `启动.cmd`，停服务双击 `停止.cmd`。

macOS / Linux：`sh 安装.sh`，其余相同。

详细说明（含「团队内网共用」「登录态怎么续」「出问题先看哪里」）见随包 `安装说明.txt`，也可以[在这里先看](安装说明.txt)。

## 第一次使用

1. 设访问口令，进入空间。
2. 「档案」页填品牌档案：你是谁、写给谁、什么调性、哪些词不能写。
3. 「写作」页选题材，模型按你的写作规范出稿，左侧可对照检查项。
4. 「发布」页接渠道账号，扫码一次，之后登录态自动续。

**你的数据不出本机**：稿件、档案、登录态、数据库全在安装目录的 `data/` 下，每个空间一个独立文件，互相看不到。整个目录拷走就是完整备份。

## 出问题先看这几条

| 现象 | 原因与办法 |
|---|---|
| 双击 `安装.cmd` 一闪而过，提示"无法运行 / 已阻止" | 包是从网上下的，Windows 打了"来自网络"标记。右键 zip → 属性 → 勾「解除锁定」→ 确定，重新解压 |
| 双击后窗口闪一下没了、也没装好 | 用管理员命令行在解压目录里执行 `安装.cmd`，错误信息会停在窗口里，截图发我们 |
| 发布按钮全部不可用 | 发布依赖没装。双击 `安装依赖.cmd`（约 14 MB，只装驱动不装浏览器） |
| 想确认哪里不对 | 在安装目录执行 `node scripts\doctor.js`，它把 Node 版本、依赖来源、目录权限、端口占用逐条打出来 |
| 同事连不上（内网共用） | Windows 防火墙挡了入站。管理员命令行执行一次：`netsh advfirewall firewall add rule name="Salient Studio" dir=in action=allow protocol=TCP localport=8810` |
| 换电脑后登录态全没了 | 登录态用 Windows DPAPI 按「本机 + 本账户」加密，拷 `data\` 不带走它。要迁就用 `node scripts\vault.js export` / `restore` |

## 校验下载

Windows 资源管理器不自带校验功能，用 PowerShell 一行：

```powershell
Get-FileHash .\salient-studio-r9.zip -Algorithm SHA256
```

macOS / Linux：

```bash
shasum -a 256 salient-studio-r9.zip
```

输出应为 `80b8d1088151ae6c12b22197d892fbaf381ccdbec84f04f8294e5c8434bfc2c8`。不一致说明下载损坏或被替换，请重新下载并向我们反馈。
